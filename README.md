# Squad Dashboard Backend

API REST en Node.js/Express que conecta con Jira para el Squad Dashboard.

## Stack
- Node.js + Express
- Axios para llamadas a Jira API REST
- CORS habilitado para frontend Angular

## Puertos
- Backend: http://localhost:3000

## Setup
```bash
npm install
cp .env.example .env  # Configurar credenciales Jira
npm start
```
